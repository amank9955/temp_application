# Java Todo List Application

A console-based Todo List project written in Java. It is designed to be opened and run directly in IntelliJ IDEA.

## Features

- Add a todo
- Show all todos
- Mark a todo as completed
- Delete a todo
- Clear completed todos
- Simple menu-driven console interface

## IntelliJ IDEA

1. Open the `java-todo` folder as a project in IntelliJ IDEA.
2. Make sure a JDK is configured.
3. Open `src/Main.java`.
4. Run the `Main` class.

The project uses only standard Java classes and does not require external libraries.
